# NectarLink для Noctalia

Неофициальная сборка NectarLink для Linux с русским интерфейсом, цветами
Noctalia и расширенным локальным API для [плагина](https://github.com/vladikchi/nectarlink-plugins).

## Установка на ПК

1. Скачайте **AppImage для Linux x86‑64** из [релизов этого форка](https://github.com/vladikchi/nectarlink-noctalia/releases).
2. В свойствах файла разрешите его выполнение, затем откройте двойным щелчком.
   Распаковка, сборка из исходников и права администратора не нужны.
3. В приложении выберите русский язык при необходимости и свяжите телефон,
   если он ещё не связан. Для плагина включите **Локальный API автоматизации**
   в разделе **Настройки → Подключение и о программе**.

Пока AppImage не опубликован, на странице релизов скачивать нечего. Архив
**Source code** не является приложением, а сборки оригинала не заменяют этот форк
для работы с плагином.

Храните AppImage в постоянной папке. Если кнопка запуска в плагине не находит
приложение, укажите полный путь к AppImage в настройке **«Приложение NectarLink»**.
Обновление — вручную из релизов этого форка: сначала закройте NectarLink, в том
числе в трее. Профиль хранится отдельно от AppImage; перед обновлением не нужно
отвязывать телефон. Автообновление из оригинального проекта в Linux-сборке отключено.

### NixOS и системные зависимости

AppImage рассчитан на разные дистрибутивы Linux, но не заменяет системные
компоненты. Если на NixOS он не открывается напрямую, предусмотренный NixOS
способ запуска — `appimage-run ./имя-файла.AppImage`. Этот пакет на NixOS ещё
нужно проверить. Для захвата экрана, удалённого ввода и виртуальной камеры могут
понадобиться дополнительные системные компоненты и разрешения.
